# AI Chatbot Backend

A simple FastAPI backend for a chatbot API.

## Requirements

- Python 3.11+
- `pip`

## Install

```bash
python -m pip install -r requirements.txt
```

## Run

Copy `.env.example` to `.env` and set your database credentials and API key.
The application and Alembic share the settings in `app/config/config.py`.

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## Database migrations

With PostgreSQL running and the `DB_*` settings configured, create the tables:

```bash
alembic upgrade head
```

For Docker Compose, start PostgreSQL and run migrations in a backend container:

```bash
docker compose up -d postgres
docker compose run --rm backend alembic upgrade head
```

The `users` table contains a UUID `id`, unique required `email`, optional `name`,
and timezone-aware `created_at` and `updated_at` timestamps. The `threads` table
contains a UUID `id`, required indexed `user_id`, optional `title`, and the same
timestamps. Deleting a user cascades to their threads. UUIDs are generated by
SQLAlchemy; timestamps default in the database, and `updated_at` advances on
SQLAlchemy updates. Relationships require explicit loading (for example,
`selectinload(User.threads)`) to avoid implicit database I/O in async code.

Create future migrations after changing the models:

```bash
alembic revision --autogenerate -m "Describe the schema change"
```

To undo the initial migration (deletes both tables and their data):

```bash
alembic downgrade base
```

Run migration and model regression tests against an in-memory database:

```bash
python -m unittest discover -s tests -v
```

## Docker

Build the Docker image:

```bash
docker compose build
```

Start the app using Docker Compose:

```bash
docker compose up
```

The FastAPI app will be available at `http://localhost:8000` and the automatic docs at `http://localhost:8000/docs`.

## API

### POST /chat

Request body:

```json
{
  "prompt": "Hello, how are you?",
  "model": "gpt-4"
}
```

Response:

```json
{
  "prompt": "Hello, how are you?",
  "model": "gpt-4",
  "response": "This is a generated reply from the chatbot backend."
}
```
